# ABM DIGITAL WORKFORCE – SME

> **100 Skill vận hành doanh nghiệp** dành cho A.I Agent — bộ kỹ năng "nhân sự số" cho doanh nghiệp vừa và nhỏ (SME), theo mô hình **08 phòng ban · 50 Nhân sự số · 100 Skill** (P01–P08), cộng nhóm **P00 - Skill nền** dùng chung.

Mỗi Skill là một thư mục chuẩn gồm `SKILL.md` (hướng dẫn cho A.I) kèm `references/`, `templates/`, `scripts/`, `evals.json` khi cần. Mã Skill là tiếng Việt không dấu, chữ thường, nối gạch ngang. Định dạng tương thích **Claude Code, Claude Cowork, Claude.ai** và có thể dùng làm tài liệu hướng dẫn cho **ChatGPT Codex** và các A.I Agent khác.

> **Phiên bản 2.0 (30/10/2026):** toàn bộ 100 Skill được viết lại và đổi sang mã tiếng Việt. Ai đã cài bản 1.x (mã tiếng Anh như `executive-writing`) cần gỡ các thư mục cũ rồi cài lại.

## 🚀 Cách cài đặt

### A. Claude Code / Claude Cowork — cài nhanh bằng 1 lệnh (khuyến nghị)

Trong cửa sổ Claude Code/Cowork, chạy:

```
/plugin marketplace add dangtuabm/abm-digital-workforce-sme
/plugin install abm-digital-workforce-sme@abm-digital-workforce-sme
```

Lệnh thứ nhất thêm kho này làm *plugin marketplace*; lệnh thứ hai cài trọn bộ 100 Skill. Sau đó gõ `/` để thấy các skill, hoặc A.I tự kích hoạt theo mô tả.

### B. Claude Code / Cowork — cài thủ công (clone rồi copy)

Cách này chắc chắn hoạt động và không phụ thuộc marketplace:

```bash
git clone https://github.com/dangtuabm/abm-digital-workforce-sme.git
# Cài cho TẤT CẢ project (personal skills):
#   Windows : copy skills\*  ->  %USERPROFILE%\.claude\skills\
#   macOS/Linux:
cp -r abm-digital-workforce-sme/skills/* ~/.claude/skills/
```

Chỉ cài cho một project: copy vào `.claude/skills/` trong thư mục project đó. Muốn cài lẻ vài skill thì chỉ copy đúng thư mục skill cần.

### C. Claude.ai (bản web)

Vào **Settings → Capabilities → Skills → Upload skill**, nén từng thư mục skill thành `.zip` (mỗi zip đúng **một** `SKILL.md`) rồi tải lên. Có thể clone kho này về rồi zip từng thư mục trong `skills/`.

### D. ChatGPT Codex & các A.I Agent khác

Các công cụ này chưa có trình cài "skill" riêng, nhưng mỗi `SKILL.md` là hướng dẫn Markdown thuần — dùng trực tiếp được:

- Clone kho về workspace của agent và trỏ agent vào thư mục `skills/` như tài liệu ngữ cảnh.
- Hoặc mở `skills/<tên-skill>/SKILL.md` và dán nội dung vào khung hướng dẫn/nhiệm vụ của agent khi cần dùng kỹ năng đó.

```bash
git clone https://github.com/dangtuabm/abm-digital-workforce-sme.git
```
