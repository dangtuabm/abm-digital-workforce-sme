# USE-CASE DISCOVERY — RULES REFERENCE

1. Discovery tạo opportunity register; prioritization mới chấm điểm/xếp hạng; readiness đánh giá điều kiện tổ chức.
2. Trace bắt buộc: outcome → value stream/process → role/user → job/task/decision → pain/evidence → input/data/system → output/action/acceptance → value hypothesis/metric → authority/risk → validation.
3. Task decomposition giữ trigger, steps, handoffs, exceptions và consumer; không thay job bằng nhãn "A.I thay người".
4. Evidence tách observed, documented, system-derived, self-reported, estimated và hypothesis; ghi owner/rights/date/coverage/quality/conflict.
5. Pain không có evidence là hypothesis. Missing metric là validation gap, không bịa ROI/savings.
6. Capability pattern không phải solution commitment; luôn xét no-A.I, rule, template, process fix và human-service alternative.
7. Basic screen chỉ dùng VALIDATE/DEFER/EXCLUDE; không score/rank.
8. Data cần SoR/owner/rights/class/access/quality; output cần acceptance/consumer/action; action cần human authority/Red Line.
9. Coverage map phát hiện sampling bias, thiếu frontline/customer/exception work và duplicate/bundled opportunities.
10. Không scrape/suy luận nhạy cảm, surveillance, outreach, vendor selection, automation approval hoặc publication.

## Tham chiếu nội bộ

- 8 Yếu Tố ABM: Bài toán · Dữ liệu · Công cụ/Model · Skill · Workflow · Output · Tương tác · Con người/Văn hóa.
- CUSTOMER-XRAY cung cấp logic điều tra bối cảnh/pain/source; không kéo sales profiling hoặc DISC vào discovery.
- QUICK-BIG-WINS chỉ dùng downstream cho bài tập đào tạo, không phải chuyên gia của Skill này.
